# 백로그 (남은 문제)

Phase 0 태스크의 리뷰와 결정에서 나온 후속 과제를 한곳에 모은다. 다른 문서는 이 ID 로 링크한다.

- **ID:** `P0A-`, `P0B-`, `P0C-`, `P0D-`(P0-D 리뷰) 는 그 태스크의 리뷰 지적 번호를 붙인 것이다. `P101-Tn` 은 P1-01 테스트에서 나온 결함이다. `P103-n` 은 P1-03 의 계획과 구현에서 범위 밖으로 남긴 후속이다. `P104-n` 은 P1-04 의 계획과 구현에서 범위 밖으로 남긴 후속이다. `P104-Rn` 은 P1-04 리뷰 1회차 지적이다(리뷰의 R 번호 그대로). `P105-Rn` 은 P1-05 리뷰 1회차 지적 가운데 남은 것이다. `P106-n` 은 P1-06 의 계획과 구현에서 범위 밖으로 남긴 후속이다. `P107-n` 은 P1-07 의 계획과 구현에서 범위 밖으로 남긴 후속이다. `P107-Rn` 은 P1-07 리뷰 1회차 지적 가운데 남은 것이다(리뷰의 R 번호 그대로, P1-08a 에서 적음). `PLAT-n` 은 플랫폼 검증, `DOC-n` 은 문서 과제, `CI-n` 은 CI 과제다.
- **출처:** 팩토리 태스크 ID 와 리뷰 회차다. P0-A 는 T-20261115-233911-3446, P0-B 는 T-20261117-204259-6611, P0-C 는 T-20261118-095453-0662, 문서 기준선은 T-20261119-074437-3980, P0-D 는 T-20261120-181159-c278, P1-01 은 T-20261120-201859-48d5, P1-02 는 T-20261121-212628-12b7, P1-03 은 T-20261122-093948-3537, P1-04 는 T-20261122-234625-5340, P1-05 는 T-20261123-092353-8e1d, P1-06 은 T-20261123-103009-16f8, P1-07 은 T-20261123-164312-7774, P1-07a(Windows CI 의 selftest i6) 는 T-20261123-234733-7f09, P1-07b(Windows CI 의 selftest d11 과 감독 시험) 는 T-20261124-070034-0f4a, P1-08a(P1-07 리뷰 R1–R7 후속) 는 T-20261124-054704-a729 이다.
- **심각도:** 리뷰가 매긴 값이다(critical, high, medium, low, info). 테스트에서 나온 항목은 테스터가 매긴 값이다. 리뷰와 테스트에서 나오지 않은 항목은 info 로 적는다.
- **목표:** 처리할 Phase 나 태스크다. 계획이며 바뀔 수 있다.
