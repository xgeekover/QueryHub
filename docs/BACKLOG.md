- **ID:** `P0A-`, `P0B-`, `P0C-`, `P0D-`(P0-D 리뷰) 는 그 태스크의 리뷰 지적 번호를 붙인 것이다. `P101-Tn` 은 P1-01 테스트에서 나온 결함이다. `PLAT-n` 은 플랫폼 검증, `DOC-n` 은 문서 과제, `CI-n` 은 CI 과제다.
- **출처:** 팩토리 태스크 ID 와 리뷰 회차다. P0-A 는 T-20261115-233911-3446, P0-B 는 T-20261117-204259-6611, P0-C 는 T-20261118-095453-0662, 문서 기준선은 T-20261119-074437-3980, P0-D 는 T-20261120-181159-c278, P1-01 은 T-20261120-201859-48d5 이다.
- **심각도:** 리뷰가 매긴 값이다(critical, high, medium, low, info). 테스트에서 나온 항목은 테스터가 매긴 값이다. 리뷰와 테스트에서 나오지 않은 항목은 info 로 적는다.
- **목표:** 처리할 Phase 나 태스크다. 계획이며 바뀔 수 있다.
